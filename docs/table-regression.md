# 表の列幅と揃えの回帰検証

`python -m tools.gallery.generate_table_cases out/tables.pptx`で、長短混在、数値列、識別子、
8列・lead付き5行、8列・leadなし6行、少数2行、従来の文字主体の表を生成する。
値は表示検証用の架空データであり、実績値ではない。

## 維持する配置

列幅は見出しと全セルの文字実測から配分する。短文セルだけに合わせて長文列を狭めず、
長文の折り返しと行高の計算を保つ。文字主体の従来3行例や、同じ行のセル高を全面変更しない。
疎な表を埋めるためのダミー項目も加えない。

先頭列は項目名として左揃え。以降は全セルが半角数値表記だけの場合に限り右揃えとし、
見出しも本文と揃える。符号・桁区切り・小数・末尾のパーセント記号は数値表記として扱う。
先頭ゼロの識別子や単位付き文字列、未測定などが混じる場合は左揃えを保ち、値を変換しない。
小数点位置を揃えるためのゼロ補完は行わない。

## 収容と停止

文字の下限10.5ptを保ち、8列でも数値と識別子を区別できるかを確認する。
lead付き6行が本文領域を超える例は、文字をさらに縮小せず`FitError`でページ分割を促す。
大量の長文を8行へ詰める入力も停止する。入力JSONへ列幅・座標・揃え方は追加しない。

保存PPTXの値・列幅合計・揃え方・文字下限を`tests/test_table_alignment.py`で検査する。
PowerPointと、CIの2書体のLibreOfficeによる全ページの一覧・原寸を別々に確認する。
