# マトリクスの点と名称

点の比率座標は情報そのものであり、名称を置くために動かさない。
文字枠は最大2インチの範囲で文字を実測し、短い名称の枠を一律に広げない。
上下・左右・斜めの8方向から選び、他の点・名称・領域端との衝突を避ける。
四象限を持つ入力では象限の境界をまたがない。

点の中心から名称枠までの最短距離は0.45インチ以内に制限する。
0.26インチを超えて横・斜めへ離す場合だけ、点の輪郭から枠の手前まで0.7ptの引出線を置く。
引出線に矢印は付けず、別の点・名称・引出線に通路が重なる候補は選ばない。
単純な短い線の矩形通路で保守的に判定するため、収容できない入力を無理に描くことはしない。

標準間隔、間隔圧縮、最大枠幅1.65インチへの縮小の順で試す。
名称は11ptを基準に最小9ptまでとし、文字が収まらない場合や密集した点の対応を維持できない場合は
`FitError`で停止する。名称の短縮・点数削減・ページ分割を行い、JSONへ文字位置を追加しない。

`python -m tools.gallery.generate_matrix_cases out/matrix.pptx`は、近接点、長い名称、端の8点、
単一点、従来の通常・lead付きの6ページを生成する。点座標・文字下限・最大距離・枠と通路の非交差は
保存PPTXと純粋な配置計算を試験し、対応の追いやすさはPowerPointと互換Officeの原寸で確認する。
