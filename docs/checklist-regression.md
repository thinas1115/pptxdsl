# チェックリストの配置回帰

チェック済み・未チェックは状態の違いであり、行の配置や項目間隔を変える条件にしない。
現行の`bullets`は、本文の自然高さを測った後に一定のgapで積む。折り返す本文でも、
チェック欄は段落全体の中央ではなく先頭行に合わせる。

標準の項目間gapは0.52in、収容が必要なときの下限は0.34inである。
本文枠には0.08inの追加高があるため、保存PPTXの枠同士の距離ではそれぞれ0.44in・0.26inになる。
この数値はrendererの内部契約であり、`content.json`へ指定するものではない。
少数項目を下端まで引き伸ばしたり、余白を埋める装飾を加えたりしない。

`python -m tests.test_checklist_spacing`は、2・4・6項目、1行と複数行、通常とlead付きの
保存PPTXで全行の間隔・先頭行合わせ・本文下端を検査する。完了状態を全反転させても配置が変わらないことと、
過密な入力を明示停止することも確認する。

`python -m tools.gallery.generate_checklist_cases out/checklist.pptx`で5ページの回帰例を作れる。
出力はレイアウト検査後にPNG化し、一覧と全原寸で確認する。backendや書体による文字・チェック記号の差は、
機械的な座標検査だけでは判定できない。
