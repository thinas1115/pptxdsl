## v1.0.4

2カラム比較の見出しと配色を整理し、対応関係図の線を追いやすくしました。

## 主な変更

- `two_column`の小さい上段ラベルとBEFORE/AFTERの自動表示を廃止し、見出しを一本化
- 2カラムは小さめの見出し、その下の細い罫線、控えめな番号と濃い本文で構成。大きな薄色パネルや項目ごとの装飾罫線を廃止
- 2カラム本文は計測済みの改行を使い、PowerPointで単語が途中分断される問題を抑制
- `relationship_map`の項目下端にあった短い装飾罫線を削除
- 対応関係図の接続点を項目中央へ統一。同じ段の線を水平に揃え、分岐・合流の端点を共有
- 線の背景マスクを無関係な線の交差部分だけに限定し、分岐・合流の根元が欠けないように調整
- ギャラリーの一覧と配布PPTXを更新

背景色・背景画像は従来のConfigをそのまま使います。共通テーマや、他のtypeの構成は変更していません。

## 既存データを使う場合

- `two_column.left.label`と`two_column.right.label`は入力互換のため受け付けますが、スライド上には表示しません。新しい入力では省略してください。
- `heading`と本文、対応関係図の項目・リンクの指定方法は変更していません。
- 余白圧縮、文字縮小、最小値でも収まらない場合の明示停止は維持しています。

## 配布物

- `pptxdsl-skill-v1.0.4.zip`: 自己完結型Skill
- `pptxdsl-plugin-v1.0.4.zip`: ChatGPT Work、Codex、Claude Code向けPlugin

Python 3.10以上、日本語フォント、PNG化の手段は利用環境側で用意します。
機械検査と実描画の確認は別の工程です。WindowsのPowerPointで変更ページを目視確認済みです。
macOS CIの成功をPowerPoint for Macの実機受入とは扱いません。
導入手順は[Release時点のREADME](https://github.com/thinas1115/pptxdsl/blob/v1.0.4/README.md)を参照してください。
