## v1.0.3

スライドの共通フレームを整理し、生成図解の絵柄と背景を揃える手順を更新しました。

## 主な変更

- 本文ページ左上の小さな分類ラベルを表示せず、タイトルと本文の利用領域を拡大
- タイトル下の説明文を濃色・標準18ptへ変更。2行表示を確保し、過密時は16pt未満へ縮小せず停止
- 下部の共通補足帯を廃止し、旧`footnote`を発表者ノートへ保持
- フッター文言をConfigで指定する会社のコピーライト等に限定し、右下のページ番号と同じ高さへ配置
- フッター上の細い罫線は維持。`footer.show_divider`で表示を切替可能
- `image`が本文の横幅を使うように調整
- 全画像へ同じ共通スタイルを付けるプロンプト組立スクリプトをSkillへ追加。採用画像を後続の絵柄参照にする手順と生成記録を整備
- 画像背景はPPTXと同じ`--template-config`から解決。単色背景色を反映し、背景画像がある場合は透過PNGを要求
- 開発中の配布テストと、公開直前のMarketplace実ZIP・URL・SHA-256照合を分離

## 既存データを使う場合

- 本文の`kicker`は入力互換の分類情報として残りますが、画面には表示しません。章扉の章ラベルは維持します。
- 旧`footnote`は画面上に表示しません。画面に必要な注意書きは`lead`または本文へ移してください。
- `meta.footer`は自動表示しません。会社表記はConfigの`footer.text`で明示してください。未指定時は罫線とページ番号のみ表示します。
- Configを変えても、生成済み画像に焼き込まれた背景色は自動変更されません。プロンプトを組み直して対象画像を再生成し、文字のコントラストを確認してください。

画像生成APIや有料契約は必須にしません。画像の内部解析、編集可能な図形への自動変換、自由座標の入力は追加していません。

## 配布物

- `pptxdsl-skill-v1.0.3.zip`: 自己完結型Skill
- `pptxdsl-plugin-v1.0.3.zip`: ChatGPT Work、Codex、Claude Code向けPlugin
- `pattern_gallery.pptx`: 28type・38枚のPowerPoint出力例
- `SHA256SUMS.txt`: 配布物のSHA-256一覧

Python 3.10以上、日本語フォント、PNG化の手段は利用環境側で用意します。
機械検査と実描画の確認は別の工程です。macOS CIの成功をPowerPoint for Macの実機受入とは扱いません。
導入手順は[Release時点のREADME](https://github.com/thinas1115/pptxdsl/blob/v1.0.3/README.md)を参照してください。
