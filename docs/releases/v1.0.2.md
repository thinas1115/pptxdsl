## v1.0.2

Claude CodeからSkillまたはPluginとして導入できる配布形式を追加しました。Codex、ChatGPT Work、Claude Codeで同じrenderer、schema、素材を使用します。

## 配布物

- `pptxdsl-skill-v1.0.2.zip`: CodexまたはClaude Codeへ直接導入する自己完結型Skill
- `pptxdsl-plugin-v1.0.2.zip`: Codex、ChatGPT Work、Claude Codeへ導入する自己完結型Plugin
- `pattern_gallery.pptx`: 対応typeのPowerPoint出力例
- `SHA256SUMS.txt`: Release本文にも表示するSHA-256を収録した自動検証用ファイル

Plugin ZIPにClaude Code用manifestを追加し、GitHub上の`pptxdsl-marketplace`からSHA-256検証付きで導入できるようにしました。Skill ZIPを`~/.claude/skills/`へ展開する方法も利用できます。

導入手順と実行環境の前提条件は、Release時点の[README](https://github.com/thinas1115/pptxdsl/blob/v1.0.2/README.md)を参照してください。
