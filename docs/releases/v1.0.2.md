## v1.0.2

レビュー対応と資料作成の導線をまとめたリリースです。

## 主な変更

- 2枚の画像を並べる`image_compare`の収容と比較ラベルを改修
- 概念説明用の画像生成プロンプト、採用前の確認、外部素材を`--asset-dir`で取り込む導線を追加
- 目次・アジェンダ用の`agenda`を追加。章名、補足、開始ページを指定可能
- 本文背景色・画像、表紙背景、フッターをまとめるテンプレート設定と雛形生成コマンドを追加
- カードのパネル化と工程表の専用列撤去は撤回し、旧デザインを維持
- 左右分割の`split`は受入時に撤回し、renderer・入力契約・ガイド・ギャラリー・配布物から削除
- 入力の構造契約をJSON Schemaへ集約し、フィールド一覧・型・件数・生成AI向け一覧を同じ定義から生成
- PPTX生成・検査コードとテスト・回帰入力・開発ツールを分離し、依存の最小化、型検査、回帰検証を整備
- フォントの検出と実測、図やグラフの検証、PNG確認の基準、Windows・Linux・macOSの品質検査を更新
- 同じPlugin ZIPへCodex・Claude Codeのmanifestを収録。Release ZIPをSHA-256で固定するClaude Code Marketplaceを追加

カード・工程表の追加改善とPowerPoint for Macの実機受入は引き続きIssueで追跡します。
利用者のPPTX/POTXマスターの丸ごと取込や、暗色本文テーマの全配色変換は含みません。

機械検査と実描画の確認は別の工程です。macOS CIの成功だけでPowerPoint for Macの実機受入を完了扱いにしません。

## 配布物

- `pptxdsl-skill-v1.0.2.zip`: CodexまたはClaude Codeへ直接配置する自己完結型Skill
- `pptxdsl-plugin-v1.0.2.zip`: ChatGPT Work、Codex、Claude Code向けの自己完結型Plugin
- `pattern_gallery.pptx`: 28type・38枚のPowerPoint出力例
- `SHA256SUMS.txt`: 配布物のSHA-256一覧

Python 3.10以上、日本語フォント、PNG化の手段は利用環境側で用意します。
導入手順は[Release時点のREADME](https://github.com/thinas1115/pptxdsl/blob/v1.0.2/README.md)を参照してください。
